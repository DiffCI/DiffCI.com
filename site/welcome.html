Installed

You're set up. Nothing changed in your CI.

The App has exactly the four read-only permissions it asked for — metadata, contents, Actions, checks — and nothing else. It cannot push, comment, label, cancel a run, or change a check status. That's not a promise about our conduct; GitHub enforces it structurally.

Where your code goes

"Read-only" answers what DiffCI can change. It does not answer what DiffCI can see, so here is that answer, permission by permission.

ContentsFor each commit it analyzes, DiffCI makes a shallow clone of your repository at that commit, inside an ephemeral container on infrastructure operated solely for DiffCI. This is what the contents permission is for: there is no way to build a real dependency graph without reading the source.
What happens to the cloneThe graph is computed and the container is destroyed. The clone does not outlive the analysis. No copy of your source tree is kept anywhere, and no file contents are written to any store.
What is keptCommit SHAs, the paths of changed files, the tests DiffCI would have selected, the reason it fell back to a full run when it did, and the reconciled outcome and timings of the CI run that actually happened. Plus evidence archives for those analyses, so a result can be audited rather than taken on trust. Never file contents. Never credentials: DiffCI is not given any.
For how long90 days at most, counted from the analysis that produced each record. Uninstalling the App deletes that repository's records sooner, automatically.
Actions, checksRead the results and timings of workflow runs that have already finished. This is the same information the Actions tab shows you, used to check DiffCI's prediction against what your CI actually did.
Pull requestsNot requested. DiffCI does not read pull request titles, descriptions, diffs, or review comments. The App asked for this scope in an earlier version without using it; it was removed. If pull-request-level analysis is built, the App will ask for the permission then, and GitHub will prompt you to approve it.
Who else sees itNobody. Nothing is sold, shared with a third party, or used to train anything, and nothing naming your repository is published without your written agreement to that specific text.

If your repository is private and the clone is the part you are not comfortable with, that is a reasonable position. Uninstall, and the records go with it. The data-handling page is the full version of this section.

What happens now

Right nowDiffCI starts observing pushes to your default branch and reading the results of workflow runs that finish. It changes nothing about how those runs execute.
Over the next 7 daysEach observed commit gets analyzed: a real dependency graph, a selection DiffCI would have made, then a reconciliation against what your CI actually did. Every one of those is stored so it can be inspected later, not just asserted.
On day 7Your first report is ready — what DiffCI observed, what it thinks was avoidable, and whether any change it would have deprioritized turned out to break something. See below for where to find it.
If you don't want to waitThe report updates continuously as more commits are observed — check it any time; a thin sample just means DiffCI says so plainly instead of guessing.

Find your report

Every enrolled repository has a live report at a URL built from its "owner/name" — bookmark yours now. DiffCI does not collect an email address and will not send you anything: there is no message on day 7, only this URL.

Nothing to configure. Within a minute of installing, DiffCI reads the repository’s own workflow files and package.json scripts to identify which GitHub Actions workflow runs its tests, and the report shows that identification and its reasoning. If no workflow runs the tests on push or pull request, the report says exactly that instead of showing zeros.

A private repository’s report is not public by URL: its link (with a report token) is shown in the DiffCI dashboard after signing in with GitHub - GitHub itself confirms you can access the repository - so nobody can read your CI timings by guessing the repository name.

The report is a plain-text page, not a dashboard yet — deliberately: every figure on it is labeled MEASURED, ESTIMATED, or UNKNOWN, and that discipline matters more right now than the styling does. The same URL always shows the current state; there's nothing to configure or refresh manually.

What DiffCI never does in shadow mode

  • Never skips, cancels, or modifies a run. Shadow mode has no CI authority to give away — the install itself grants none.
  • Never writes to your repository. No commits, comments, labels, or check statuses.
  • Never turns an estimate into an invoice. Everything in the report is labeled by evidence level, and nothing is billed against an ESTIMATED figure, ever.
