Try one observation before changing CI

Analyze the current checkout without executing tests or sending a report:

npx "@diffci.com/diffci@latest" observe --no-send

Use check only when repository test commands are allowed to run. A fallback is useful evidence that the change could not be narrowed safely; it is not a reason to remove required CI.
