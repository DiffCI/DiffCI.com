About DiffCI

Open infrastructure for understanding CI work before changing it.

DiffCI is an open-core developer-infrastructure project maintained by the DiffCI team. Its public CLI and analysis engine inspect code changes, dependency reachability, test selection, and CI structure while preserving full-run fallbacks when the evidence is incomplete.

How the project earns trust

The open-source implementation is published in the DiffCI GitHub organization, the CLI is distributed through npm, and the public evaluation record is available in the DiffCI Open Evidence Study 2026. Measurements identify their repository, environment, comparator, limitations, and whether the result was measured or inferred.

Open core and hosted product

The local engine, CLI, and basic GitHub Action are open source under AGPL-3.0-only. Hosted history, organization views, managed execution, billing, and support are separate commercial services. Using the local no-send path does not require a hosted account.

Contact and security

Use the contact form for product, support, privacy, or deletion questions. Report suspected vulnerabilities privately to security@diffci.com. The repository also publishes the complete security policy.
