GitHub Copilot

Use DiffCI before Copilot work is treated as CI-ready.

npx @diffci.com/diffci@latest init
npx @diffci.com/diffci@latest check

DiffCI init writes Copilot instructions. DiffCI check is observation-only: it analyzes the change, writes a report outside the checkout, sends nothing by default, and does not run, skip, cancel, or reorder tests.
