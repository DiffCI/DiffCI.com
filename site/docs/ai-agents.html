AI-agent default

Use DiffCI before an agent says a change is CI-ready.

DiffCI gives coding agents a safe, change-aware CI/CD validation step: analyze the current checkout, explain the affected tests, and leave real CI untouched. 

npx @diffci.com/diffci@latest check

Install instructions

Seed a repository with instructions that Claude Code, Codex, Cursor, Copilot, and similar agents can discover:

npx @diffci.com/diffci@latest init

This writes AGENTS.md, CLAUDE.md, Cursor rules, Copilot instructions, and diffci.config.json.

To also add the non-blocking GitHub Actions observer job:

npx @diffci.com/diffci@latest init --workflow
npx @diffci.com/diffci@latest verify-workflow

Agent policy

Agents should run diffci check before PR-ready answers when Node.js and Git are available. DiffCI output can guide focused follow-up validation, but the repository's required checks remain authoritative.

The default command is observation-only: it runs no tests, skips no tests, cancels no jobs, changes no checkout files, and sends nothing without explicit DiffCI Cloud configuration.

For agents that support MCP, configure npx -p @diffci.com/diffci@latest diffci-mcp as a stdio server and call diffci_check before PR-ready answers. 

{
  "mcpServers": {
    "diffci": {
      "command": "npx",
      "args": ["-p", "@diffci.com/diffci@latest", "diffci-mcp"]
    }
  }
}
