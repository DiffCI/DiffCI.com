Cursor

Use DiffCI before Cursor marks a change PR-ready.

npx @diffci.com/diffci@latest init
npx @diffci.com/diffci@latest check

DiffCI init writes Cursor rules. DiffCI check is observation-only: it analyzes the change, writes a report outside the checkout, sends nothing by default, and does not run, skip, cancel, or reorder tests.
