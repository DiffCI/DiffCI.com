# Permalinks

URLs on diffci.com that external citations depend on. **Each is a promise: the URL never changes and,
for a versioned file, the bytes never change either.** `tests/open-study/permalinks.test.ts` fails CI
if a path below goes missing or a pinned file's SHA-256 changes.

## Rules

1. **Versioned files are immutable.** A `-v1` file is never edited, re-rendered or moved. A correction
   is a new `-v2` file at a new URL, with a new row here; the old row and file stay forever, so a
   citation made today still resolves to the exact document that was cited.
2. **Unversioned study artefacts may be re-rendered, never moved.** The study page, its CSV, its PDF
   and LICENSE.txt are regenerated by `npm run study:render` when the findings module changes. Their
   URLs are fixed; their content is the current version of the study, and the study id
   (`diffci-oes-2026-v1`) inside them changes if the findings do.
3. **Never redirect a permalink.** Cloudflare `_redirects` would work, but a redirect is a URL that
   someone will eventually clean up. The file stays where it was cited.
4. **No file is currently versioned.** If one is ever added, give it a one-year immutable
   `Cache-Control` rule in `site/_headers`; that is correct only because of rule 1.

## Adding a permalink

1. Put the file under `site/` at its final path. Version it (`-v1`) if the bytes must never change.
2. Add a row here; for a versioned file, record `sha256sum` of the file.
3. Add it to `PERMALINKS` in `tests/open-study/permalinks.test.ts`.
4. Deploy. Only then cite it anywhere external.
