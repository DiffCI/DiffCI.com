# DiffCI 0.3.1

DiffCI 0.3.1 is the stable publication of the two-pilot agent-verification release described in the
[0.3.0 release note](0.3.0.md).

The release workflow now installs the repository with Node 24's bundled npm before installing the
OIDC-capable npm 11 publisher. This preserves the commit-pinned DiffCI Core dependency while preventing
future npm major-version changes from altering the clean-install release gate. GitHub Actions are pinned
to immutable v7 commit SHAs, and the unsupported `package-manager-cache` input has been removed.

No 0.3.0 package was published. Its workflow failed closed during `npm ci`, before the publish step, and
the `v0.3.0` tag remains unchanged for auditability.
