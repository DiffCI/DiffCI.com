# DiffCI 0.1.4

Tests outside a TypeScript compiler's include list now contribute their real import edges to the
dependency graph. Previously, such tests could be counted but disconnected, causing incomplete
selections even when graph confidence was reported as COMPLETE. Discovered JavaScript tests and
their helpers are parsed too. Existing graph caches are invalidated.

Revalidate observations from 0.1.3 or earlier when tests were excluded by compiler configuration.
The CLI and Action remain observation-only; this release does not skip or execute host tests.

The workflow guard no longer mistakes literal npm registry tag-removal commands for observer
invocations. Actual observer commands elsewhere in the same script remain audited. Prerelease
publishing also preserves the existing stable latest tag.

Regression coverage includes source-only compiler configurations, nested packages, JavaScript test
helpers, unresolved imports, and registry commands mixed with real observer invocations. The package
smoke test now exercises excluded-test dependency selection from the installed tarball.
