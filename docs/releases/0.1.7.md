# DiffCI 0.1.7

This patch hardens the opt-in runtime pilot introduced in 0.1.6.

`verify-savings --selected-from-report` now requires the observation report to contain exactly one
non-empty proposed command. Reports with multiple commands are refused before the full or selected
command is executed, because timing only the first command would under-measure the selected arm.

Failed timing pairs are now labelled as invalid evidence in the console summary and Markdown report
instead of being described as faster or slower. The command outputs and timings remain in the report
for diagnosis.

The CLI catch path now keeps observe's non-failing CI behavior while returning exit code 1 for thrown
errors from `pilot` and `verify-savings`.

Documentation now states that `pilot` and `verify-savings` execute repository commands, that those
commands can mutate the checkout, and that one paired timing run is only preliminary evidence.
